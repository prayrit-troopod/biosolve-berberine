# BioSolve Berberine — static page mirror

Static snapshot of the GATACA BioSolve Berberine product page, served via GitHub Pages.

- `index.html` — the page
- `assets/` — images, CSS, fonts and scripts saved with the page

Shopify runtime calls (cart, checkout, analytics pixels) 404 by design: there is no
backend behind a static mirror. Layout, copy and imagery render as captured.
